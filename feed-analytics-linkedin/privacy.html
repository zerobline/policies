Privacy Policy

Product: Feed Analytics for LinkedIn
Effective date: 27 September 2026

Summary: The extension does not transmit or remotely store LinkedIn feed data. It reads information already displayed in the user's LinkedIn feed and processes it locally in Microsoft Edge to categorize and visualize the feed.

Information processed by the extension

To provide its user-facing features, the extension reads information already rendered on LinkedIn pages, including visible feed-card text and metadata, names of people or organizations shown on feed cards, LinkedIn profile/company/group/page links, and visible labels used to classify feed items.

How information is used

This information is used only to categorize visible LinkedIn feed items, display local counts and summaries, apply user-selected feed filters, show source details, and generate a CSV file when the user explicitly requests an export.

Local processing and storage

Feed analysis is performed locally in the user's browser. Current feed analytics and counts are held in memory for the active browsing session.

The extension stores only interface preferences, such as hidden feed categories and whether the details panel is open, using Microsoft Edge extension storage.

Data transmission and sharing

The extension does not send LinkedIn feed data, profile information, analytics results, browsing activity, or exported CSV content to the developer or to any remote server.

The extension does not include a third-party analytics service, advertising service, tracking SDK, remote database, or remote processing service.

CSV exports

A CSV file is generated only after the user explicitly selects the CSV export function. The file is created locally in the browser and may contain the source names and LinkedIn URLs that were visible to the extension during the user's session.

Sale and advertising use

The extension does not sell user data and does not use processed information for advertising, profiling, credit, lending, employment, insurance, or eligibility decisions.

User control

Users can change feed-category filters, reset in-session analytics, create a CSV export, disable the extension, or uninstall it at any time. Removing the extension also removes its extension-local preferences.

Third-party service

The extension operates on linkedin.com but is not affiliated with, endorsed by, or sponsored by LinkedIn Corporation or Microsoft. LinkedIn's own handling of information is governed by LinkedIn's policies and is outside the control of this extension.

Changes to this policy

If the extension's information-handling practices change, this policy will be updated before a version containing those changes is published.

Contact and support

For questions about this policy or the extension, use the support page.
