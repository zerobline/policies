## Projects

### Feed Analytics for LinkedIn

Privacy policy and support documentation for the Microsoft Edge extension **Feed Analytics for LinkedIn**.

### Time Telling for Kids

Privacy policy and public product information for the Android app **Time Telling for Kids**.

## Publishing

This repository is structured as a static GitHub Pages site. In GitHub:

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**.
4. Save.

GitHub will publish the site under `https://zerobline.github.io/policies/`.
